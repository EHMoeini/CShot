#  CShot

> **Two-player shooting game built with Python & Pygame.**

CShot is a **two-person collaborative university project** developed for the **Advanced Programming course at Iran University of Science and Technology (IUST)**.

##  Features

*  Two-player real-time gameplay
*  Dynamic targets & shooting mechanics
*  Distance-based scoring system
*  Time & arrow bonuses
*  Login & Signup system
*  SHA-256 password hashing
*  Persistent leaderboard
*  JSON-based account storage
*  Object-Oriented design

##  Controls

| Player | Movement   | Shoot   |
| ------ | ---------- | ------- |
| 🔵 P1  | `W A S D`* | `ENTER` |
| 🟠 P2  | `W A S D`  | `SPACE` |

> *Player 1 uses the **Arrow Keys** for movement.*
